# Git základní školení – materiál

Tento repozitář slouží jako praktický tréninkový projekt. Cílem je osvojit si základní principy práce s repozitářem, větvemi a historií změn.

---

## 🎯 Cíl
Seznámit účastník s:

- stáhnout repozitář
- vytvořit větev
- provést změnu
- commitnout změnu
- pushnout změny na server
- sloučit větev zpět

---

## 📦 Co je repozitář
Repozitář je složka projektu, která obsahuje:

- soubory projektu
- historii změn
- informace o verzích

## To není vše
Ještě k tomu je výklad a prezentace.
